# LOL Support Advisor

개인용, 읽기 전용 리그 오브 레전드 서포터 픽 보조 GUI입니다.

비공식 개인용 도구이며 Riot Games가 보증하거나 공식 지원하지 않습니다. Riot Games 및 관련 자산은
Riot Games, Inc.의 상표 또는 등록상표입니다.

## 주요 기능

- 실행 중인 League Client의 챔피언 선택 세션을 읽기 전용으로 감시
- Riot Data Dragon 현재 패치의 전체 챔피언 아이콘을 백그라운드에서 순차 다운로드해 로컬 캐시
- 확정 픽, 아군 픽 의사(HOVER), 밴, 내 픽 순서를 구분
- 상대 픽을 클릭해 적 서포터를 직접 지정하고, 명확한 서포터는 `확실하지 않은 자동 추정`으로 표시
- 적 서포터를 판단할 수 없을 때 `서포터 모르겠음`을 선택해 ChatGPT에 블라인드 판단 요청
- OP.GG 카운터/승률 캐시와 성공 후 1시간 갱신 쿨타임
- ChatGPT용 고정 규칙 질문을 한 번에 복사하고, 별도 창에서 전송할 질문 전체 미리보기
- ChatGPT JSON 답변을 붙여넣고 스냅샷·중복·밴/픽 충돌을 검증
- OP.GG 전체 통계, 내 챔피언 전적, 내 맞상대 전적을 분리 표시
- 세 데이터를 조합한 후보 종합점수·표본 신뢰도, 서폿 유형 필터, `TOP 3 후보 복사`
- 후보 여러 명의 개인 전적을 DB 한 번 순회로 일괄 계산하고, DB/상대 서포터가 바뀔 때까지 메모리 캐시
- Riot Match-v5 최근 솔로랭크 최대 1,000경기를 SQLite에 누적 저장해 로컬 계산
- `선택창`, `플레이`, `내 전적` 3탭 제공, 게임 시작 시 플레이 탭으로 자동 전환
- 플레이 탭에서 아군/적군 5명, 시즌 승패·승률, 현재 챔피언 표본, 나와의 전적 표시
- 플레이 탭을 아군 5장·적군 5장 카드 보드로 표시해 포지션별로 즉시 비교
- 각 카드에서 시즌 승패 막대, 현재 챔피언 표본, 전판 승패·KDA, 나와의 기록, DUO 신호를 압축 표시
- 내 전적 탭에서 현재 랭크, 로컬 최대 1,000경기, 최근 20경기, 전체 KDA·시야, 챔피언별 성능 표시
- 최근 경기 카드에서 챔피언·KDA·CS/분·시야·아이템·양 팀 조합을 보여주고 상세창으로 연결
- 경기 상세창에서 양 팀 10명의 KDA·CS·시야·피해량·아이템과 내 전투/시야 지원 지표 비교
- 아군/적군 각 플레이어의 전판 솔로랭크 챔피언·포지션·승패·K/D/A·KDA 표시
- 현재 게임 10명의 최근 경기 교집합을 이용한 3단계 `DUO 추정` 배지 표시

게임 수락, 챔피언 선택, 룬 변경 등 League Client에 값을 쓰는 기능은 없습니다.

## 실행

Python 3.11 이상이 필요합니다. 외부 Python 패키지는 필요하지 않습니다.

```powershell
python app.py
```

화면만 먼저 확인하려면 다음 데모 모드를 사용합니다. 데모의 OP.GG 수치는 레이아웃 확인용 예시입니다.

```powershell
python app.py --demo
```

Windows에서 `python` 명령이 없다면 Python 설치 후 아래 `run.bat`을 더블 클릭할 수 있습니다.

## 사용 순서

1. 앱을 실행하고 롤 챔피언 선택 화면에 들어갑니다.
2. 자동 추정이 틀리면 상대 챔피언을 클릭해 적 서포터를 지정합니다. 아직 모르면 `서포터 모르겠음`을 선택합니다.
3. 필요한 경우 `OP.GG 데이터 갱신`을 누릅니다. 성공 후 1시간 동안 버튼이 잠깁니다.
4. 필요하면 `보낼 질문 미리보기`로 내용을 확인하고, `ChatGPT 질문 복사`를 눌러 원하는 채팅에 붙여넣습니다.
5. ChatGPT 답변 전체를 복사한 뒤 `클립보드 답변 붙여넣기`를 누릅니다.
6. 게임이 `InProgress`가 되면 앱이 자동으로 `플레이` 탭으로 이동합니다.

픽·밴·호버가 질문 복사 후 바뀌면 스냅샷 ID가 달라져 오래된 답변을 거부합니다.
롤 클라이언트 폴링 중 픽·밴·호버가 그대로면 선택창을 다시 만들지 않습니다. 개인 전적의 첫 계산은
백그라운드에서 실행되어 잠시 `계산 중...`으로 표시되며 UI 입력을 막지 않습니다.

## 내 전적 설정

상단 `Riot 설정`에서 다음 값을 입력합니다.

- Riot Developer Portal에서 발급한 API 키

게임 이름, 태그와 PUUID는 실행 중인 롤 클라이언트에서 자동 감지합니다. API 키를 한 번 저장하면 앱 시작
시와 게임 종료 후 자동으로 최근 솔로랭크 최대 1,000경기를 `data/advisor.db`에 동기화합니다. Match-v5는
100개씩 페이지를 나누어 조회하고 이미 저장한 경기 상세는 다시 요청하지 않습니다. 짧은 시간에
중복 요청하지 않도록 자동 동기화에는 10분 간격 제한이 있습니다. `전적 데이터 미리 갱신` 버튼을 누르면
내 전적에서 아직 저장하지 않은 경기만 추가합니다. 최근에 만난 다른 9명을 별도로 사전 조회하지는 않습니다.
API 키는 로컬 SQLite에 평문으로 저장되므로 개인 PC에서만 사용하고 저장소에 DB를 올리지 마세요. 개발용
키는 약 24시간마다 만료되므로 상단에 저장 시각 기준 남은 시간을 표시하며, `Riot 키 발급/갱신` 버튼으로
Developer Portal을 열 수 있습니다. 새 키는 `Riot 설정`의 빈 키 입력란에 넣어 교체합니다. 저장 버튼을
누르면 현재 Riot ID의 계정 확인 요청으로 키를 먼저 검증하며, PUUID가 정상 반환될 때만 기존 키를
교체합니다. 만료/잘못된 키와 네트워크 연결 실패를 구분해 표시하고 실패한 새 키는 저장하지 않습니다.

플레이 탭의 `이번 시즌 승패`는 Riot League-v4의 시즌 솔로랭크 전체 기록입니다. `현재 챔피언`은
API 호출량을 과도하게 늘리지 않기 위해 해당 플레이어에 대해 로컬에 저장된 최근 최대 20경기 중 그
챔피언을 플레이한 횟수와 승률로 표시합니다. 실제 저장 표본 수도 카드에 함께 표시합니다. `나와 기록`은
내 로컬 최대 1,000경기에서 같은 팀과 상대 팀을 나누어 계산합니다.
마지막으로 만난 경기가 내 직전판인지/최근 몇 번째 완료 경기인지, 당시 팀 관계·승패·양쪽 챔피언과
내 최근 10판 안의 동팀/상대 횟수도 별도 줄로 표시합니다.
플레이 탭의 챔피언·나와의 전적은 `data/advisor.db`만 읽습니다. 다만 현재 참가자의 시즌 랭크가 24시간
캐시에 없으면 듀오 검사와 함께 League-v4를 한 명당 한 건만 조회해 저장합니다. 각 참가자의 최신 솔로랭크
경기 상세도 기존 40건 상세 요청 예산 안에서 우선 저장해 전판 챔피언·포지션·승패·K/D/A·KDA를 표시합니다.
로컬에 없는 처음 만나는 플레이어는 `로컬 데이터 없음`으로 표시되며, 게임 종료 후 본인 전적과 방금 만난
플레이어의 관계 기록이 자동으로 저장됩니다. 처음 최대 1,000경기를 받는 작업은 개발용 Riot API 키의
속도 제한 때문에 몇 분 이상 걸릴 수 있지만, 이후에는 신규 경기 상세만 받습니다.

Riot Live Client API에는 공식 파티 ID가 없으므로 듀오는 확정값이 아닙니다. 듀오 검사만 게임 시작 후
예외적으로 Riot API를 사용합니다. 현재 10명 각각의 최근 솔로랭크 100경기 ID는 1명당 한 요청으로 받고,
같은 팀 두 사람에게 공통 경기 ID가 있을 때만 상세를 확인합니다. 계정 확인 10건, ID 목록 10건, 시즌 랭크
10건, 경기 상세 40건으로 한 게임 최대 약 70건을 넘지 않습니다. 한 쌍당 공통 경기 상세도 최대 5건만
확인합니다.

- `DUO 매우 유력`: 서로의 직전 2경기가 모두 같은 팀
- `DUO 유력`: 직전판도 같은 팀이라 현재 게임까지 2연속이거나, 최근 기록 안에서 2경기 연속 같은 팀
- `DUO 가능`: 연속은 아니지만 최근 100경기 안에서 같은 팀으로 2회 이상 확인

직전 경기가 아닌 한 번의 우연한 동팀 기록만 있으면 배지를 표시하지 않습니다.

## OP.GG 주의사항

OP.GG는 공개 집계 API를 제공하지 않으므로 공개 웹페이지를 낮은 빈도로 읽는 방식입니다. 페이지 형식이
바뀌면 파서가 임의의 수치를 표시하지 않고 갱신 실패로 처리합니다. 마지막 정상 캐시는 유지됩니다.
