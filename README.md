# LOL Support Advisor

개인용 리그 오브 레전드 포지션별 픽·빌드 보조 GUI입니다.

비공식 개인용 도구이며 Riot Games가 보증하거나 공식 지원하지 않습니다. Riot Games 및 관련 자산은
Riot Games, Inc.의 상표 또는 등록상표입니다.

## 주요 기능

- 실행 중인 League Client의 챔피언 선택 세션을 실시간 감시하고, 사용자 요청 시 로컬 LCU 작업 실행
- Riot Data Dragon 현재 패치의 전체 챔피언 아이콘을 백그라운드에서 순차 다운로드해 로컬 캐시
- 확정 픽, 아군 픽 의사(HOVER), 밴, 내 픽 순서를 구분
- 내 배정 포지션(탑/정글/미드/원딜/서폿)을 자동 감지해 후보·OP.GG·ChatGPT 규칙 전환
- 상대 픽을 클릭해 동일 포지션 상대를 직접 지정하고, 역할이 명확하면 `확실하지 않은 자동 추정`으로 표시
- 동일 포지션 상대를 판단할 수 없을 때 `모르겠음`을 선택해 ChatGPT에 블라인드 판단 요청
- OP.GG 현재 포지션 종합 순위·승률·픽률·밴률과 상대 카운터를 별도 패널·캐시로 표시
- OP.GG·빌드·조합·플레이어 통계는 쿼리별 로컬 캐시를 먼저 표시하고, 같은 요청의 재사용 시간은 `Riot 설정`에서 항목별로 변경
- 챔피언 선택 중 내 HOVER가 바뀌면 적 같은 포지션과의 OP.GG 승률·표본, 내 맞상대 전적, 원딜 조합을 즉시 카드로 비교하고 확정 전 배지로 구분
- 상단 `캐시 관리` 창은 `전체 작업`과 `챔피언별`로 구분하며, 5포지션 전체 상성·메타와 개별 챔피언의 포지션별 빌드/상성을 따로 저장
- 챔피언 아이콘은 빠진 파일만 받고, 내 1000경기는 이미 저장된 경기 ID를 건너뛰어 새 경기만 추가
- ChatGPT 로그인 기반 Codex CLI를 콘솔 없이 호출하고 전용 `thread_id` 대화를 계속 재사용
- Riot 설정에서 `1회 규칙 보내기`를 누르면 빈 `thread_id`일 때 새 대화를 만든 뒤 ID를 자동 저장
- 선택창의 `Codex CLI로 추천 받기`는 Luna/none 초고속 설정을 우선 사용하고 결과 3개를 즉시 적용
- ChatGPT용 고정 규칙 질문을 한 번에 복사하고, CLI 실패 시 쓸 수동 복사·붙여넣기 방식도 유지
- ChatGPT JSON 답변을 붙여넣고 스냅샷·중복·밴/픽 충돌을 검증
- 추천 카드별 `HOVER`·`픽 확정`·`밴 확정` 버튼과 실행 직전 보유·밴·현재 순서 재검사
- 기본 OFF인 `자동 수락`, `럭스 자동 밴` 독립 토글과 실패 시 자동 OFF·직접 조작 안내
- 럭스 자동 밴은 초기 픽 의사 표시(`PLANNING`)를 건너뛰고, 실제 밴 단계(`BAN_PICK`)의 내 차례에서만 UI와 분리된 전용 감시로 매 게임 무작위 종료 약 10~12초 전에 실행
- OP.GG 전체 통계, 내 챔피언 전적, 내 맞상대 전적을 분리 표시
- 세 데이터를 조합한 후보 종합점수·표본 신뢰도, 서폿 유형 필터, `TOP 3 후보 복사`
- 서폿 유형 필터는 전체 상성표에서 계산해 `견제·딜` 후보가 상위 10명 밖이어도 표시하고 불리한 상성은 따로 경고
- 후보 여러 명의 개인 전적을 DB 한 번 순회로 일괄 계산하고, DB/상대 서포터가 바뀔 때까지 메모리 캐시
- Riot Match-v5 최근 솔로랭크 최대 1,000경기를 SQLite에 누적 저장해 로컬 계산
- `선택창`, `플레이`, `내 전적`, `빌드 적용` 4탭 제공, 게임 시작 시 플레이 탭으로 자동 전환
- 플레이 탭에서 아군/적군 5명, 시즌 승패·승률, 현재 챔피언 표본, 나와의 전적 표시
- 플레이 탭을 아군 5장·적군 5장 카드 보드로 표시해 포지션별로 즉시 비교
- 각 카드에서 시즌 승패 막대, 현재 챔피언 표본, 전판 승패·KDA, 나와의 기록, DUO 신호를 압축 표시
- 내 전적 탭에서 현재 랭크, 로컬 최대 1,000경기, 최근 20경기, 전체 KDA·시야, 챔피언별 성능 표시
- 최근 경기 카드에서 챔피언·KDA·CS/분·시야·아이템·양 팀 조합을 보여주고 상세창으로 연결
- 경기 상세창에서 양 팀 10명의 KDA·CS·시야·피해량·아이템과 내 전투/시야 지원 지표 비교
- 경기 상세창의 전 영역 마우스 휠 스크롤, 공허 유충·전령을 포함한 팀 목표 비교
- 아이템에 마우스를 올리면 현재 패치의 한국어 이름·가격·효과 설명 표시
- 아군/적군 각 플레이어의 전판 솔로랭크 챔피언·포지션·승패·K/D/A·KDA 표시
- 현재 게임 10명의 최근 경기 교집합을 이용한 3단계 `DUO 추정` 배지 표시
- 빌드 탭에서 모든 챔피언과 현재 포지션에 맞는 OP.GG 룬·스펠·스킬 순서·아이템 빌드 표시
- OP.GG 룬 추천별 게임 수·승률과 소환사 주문 조합 최대 3개의 게임 수·승률을 함께 표시하고 선택한 조합만 적용
- 왼쪽 추천 목록에서 각 빌드의 대표 핵심 룬·아이템 아이콘을 보고 주력·대체 빌드를 비교
- 추천 룬을 시작값으로 주 룬 4줄·보조 룬 2줄·능력치 파편 3줄을 아이콘으로 직접 선택
- 룬과 아이템 아이콘에 마우스를 올리면 현재 패치의 한글 이름과 상세 효과 설명 표시
- 선택한 상대 서포터를 이니시·견제·유틸형으로 구분해 OP.GG 룬 후보와 아이템 선택지를 로컬 대응 기준으로 우선 정렬
- 점멸은 기본 `F`로 적용하며 빌드 탭의 `점멸 D`/`점멸 F` 버튼으로 변경한 뒤 로컬 설정에 저장
- 아이템 이름과 설명은 현재 Data Dragon 한국어 데이터를 우선 표시하고 스킬 레벨 순서는 1~18 표로 표시
- OP.GG 원본 순서의 기본 6칸 완성 빌드 2~3개와 선택한 상대 전용 6칸 대응 빌드 1~2개를 색상·제목으로 분리
- 기본/상대 완성 빌드와 핵심·4/5/6번째·상황별 후보를 모두 `LOL Advisor` 추천 아이템 세트에 포함
- 롤 상점 아이템 세트를 시작 아이템·소모품·핵심·최종·상대 대응·상황별·장신구 순으로 정리하고,
  블록 제목에 초반 4레벨 스킬 순서와 스킬 마스터 순서를 함께 표시
- 빌드 데이터를 받으면 룬·스펠·아이템 이미지를 로컬 캐시에 먼저 저장해 탭 전환 시 재사용
- 전체 룬 계열·슬롯·한글 설명도 League Client에서 읽어 로컬 캐시로 재사용
- `전체 챔피언 빌드 로컬 저장`으로 5개 포지션에서 실제 통계가 있는 모든 챔피언 빌드와 이미지를 순차 저장
- 전체 저장은 같은 패치의 기존 캐시를 건너뛰며 중간에 중지해도 완료된 챔피언부터 SQLite에 남아 다음 실행에서 재사용
- 사용자가 버튼을 누를 때만 `LOL Advisor` 룬 페이지, 챔피언 선택 스펠, 추천 아이템 세트 적용
- 기존 사용자·Blitz·OP.GG 룬 페이지와 아이템 세트는 유지하고 Advisor 이름의 데이터만 갱신

자동 수락과 럭스 자동 밴은 사용자가 각각 토글을 켠 경우에만 동작합니다. 추천 챔피언 HOVER·픽·수동 밴은
해당 카드의 버튼을 직접 눌러야 실행됩니다. 스킬 순서는 참고용이며 게임 중 키 입력이나 자동 스킬 레벨업은
수행하지 않습니다.

## 실행

일반 사용은 프로젝트 폴더의 `run.bat`을 더블클릭합니다. 앱은 콘솔 없는 `pythonw.exe`로
실행되고 배치 창은 즉시 닫힙니다. API 키·전적·아이콘 캐시는 프로젝트의 `data` 폴더에 보관됩니다.

소스 상태로 실행하려면 Python 3.11 이상이 필요합니다. 외부 런타임 패키지는 필요하지 않습니다.

```powershell
python app.py
```

화면만 먼저 확인하려면 다음 데모 모드를 사용합니다. 데모의 OP.GG 수치는 레이아웃 확인용 예시입니다.

```powershell
python app.py --demo
```

Windows에서는 Python 설치 후 `run.bat`을 더블클릭하면 됩니다.

## 사용 순서

1. 앱을 실행하고 롤 챔피언 선택 화면에 들어갑니다.
2. 앱이 감지한 내 포지션을 확인합니다. 자동 추정이 틀리면 상대 챔피언을 클릭해 동일 포지션 상대를 지정하고, 아직 모르면 `모르겠음`을 선택합니다.
3. `통계 캐시 확인`은 로컬 메타·상성을 먼저 사용하고 설정한 재사용 시간이 지난 쿼리만 갱신합니다. 대량 사전 저장은 상단 `캐시 관리`에서 항목별로 실행합니다.
4. 처음 한 번 `Riot 설정`에서 `1회 규칙 보내기`를 누릅니다. `thread_id`가 비어 있으면 새 Codex 대화를 만들고 자동 저장합니다.
5. 선택창에서 `Codex CLI로 추천 받기`를 누르면 같은 대화에 현재 픽 질문을 보내고 추천 3개를 자동 적용합니다. CLI를 쓸 수 없을 때만 질문 복사·답변 붙여넣기를 사용합니다.
6. 추천 카드의 `HOVER`, `픽 확정`, `밴 확정`을 필요할 때 직접 누릅니다. 자동 수락이나 럭스 자동 밴을
   원하면 상단의 각 토글을 별도로 켭니다. 실패 메시지가 뜨면 롤 클라이언트에서 즉시 직접 처리합니다.
7. 게임이 `InProgress`가 되면 앱이 자동으로 `플레이` 탭으로 이동합니다.
8. `빌드 적용` 탭에서는 챔피언을 고르고 `OP.GG 빌드 갱신`을 누른 뒤 룬·스펠·아이템 세트를 각각
   적용하거나 `전체 적용`을 누릅니다. 스펠 적용은 챔피언 선택 세션이 열려 있을 때만 동작합니다.
9. 처음 한 번 `전체 챔피언 빌드 로컬 저장`을 누르면 TOP/JGL/MID/ADC/SUP의 실제 통계 챔피언 빌드와
   이미지를 `data/advisor.db`, `data/items`, `data/build_assets`에 저장합니다. 작업 중 같은 버튼을 누르면
   현재 파일까지 저장한 후 중지하며, 다음 실행에서 이미 저장된 같은 패치 데이터는 건너뜁니다.

픽·밴·호버가 질문 복사 후 바뀌면 스냅샷 ID가 달라져 오래된 답변을 거부합니다.
롤 클라이언트 폴링 중 픽·밴·호버가 그대로면 선택창을 다시 만들지 않습니다. 개인 전적의 첫 계산은
백그라운드에서 실행되어 잠시 `계산 중...`으로 표시되며 UI 입력을 막지 않습니다.

## 내 전적 설정

상단 `Riot 설정`에서 다음 값을 입력합니다.

- Riot Developer Portal에서 발급한 API 키
- Codex CLI 전용 대화 `thread_id` — 직접 넣거나 `1회 규칙 보내기`로 자동 생성
- 내 전적·OP.GG 메타·상성·빌드·플레이어 분석·원딜 조합·로컬 자산의 재요청 시간
- 선택창에 표시할 OP.GG 메타 챔피언 개수 — 기본 5개

게임 이름, 태그와 PUUID는 실행 중인 롤 클라이언트에서 자동 감지합니다. API 키를 한 번 저장하면 앱 시작
시와 게임 종료 후 자동으로 최근 솔로랭크 최대 1,000경기를 `data/advisor.db`에 동기화합니다. Match-v5는
100개씩 페이지를 나누어 조회하고 이미 저장한 경기 상세는 다시 요청하지 않습니다. 짧은 시간에
중복 요청하지 않도록 자동 동기화에는 Riot 설정의 `내 전적 재요청` 간격을 적용합니다. `전적 데이터 미리 갱신` 버튼을 누르면
내 전적에서 아직 저장하지 않은 경기만 추가합니다. 최근에 만난 다른 9명을 별도로 사전 조회하지는 않습니다.
API 키는 로컬 SQLite에 평문으로 저장되므로 개인 PC에서만 사용하고 저장소에 DB를 올리지 마세요. 개발용
키는 약 24시간마다 만료되므로 상단에 저장 시각 기준 남은 시간을 표시하며, `Riot 키 발급/갱신` 버튼으로
Developer Portal을 열 수 있습니다. 새 키는 `Riot 설정`의 빈 키 입력란에 넣어 교체합니다. 저장 버튼을
누르면 현재 Riot ID의 계정 확인 요청으로 키를 먼저 검증하며, PUUID가 정상 반환될 때만 기존 키를
교체합니다. 만료/잘못된 키와 네트워크 연결 실패를 구분해 표시하고 실패한 새 키는 저장하지 않습니다.

플레이 탭의 `이번 시즌 승패`는 Riot League-v4의 시즌 솔로랭크 전체 기록입니다. `현재 챔피언`은
API 호출량을 과도하게 늘리지 않기 위해 해당 플레이어에 대해 로컬에 저장된 최근 최대 20경기 중 그
챔피언을 플레이한 횟수와 승률로 표시합니다. 실제 저장 표본 수도 카드에 함께 표시합니다. `나와 기록`은
내 로컬 최대 1,000경기에서 같은 팀과 상대 팀을 나누어 계산합니다.
마지막으로 만난 경기가 내 직전판인지/최근 몇 번째 완료 경기인지, 당시 팀 관계·승패·양쪽 챔피언과
내 최근 10판 안의 동팀/상대 횟수도 별도 줄로 표시합니다.
플레이 탭의 챔피언·나와의 전적은 `data/advisor.db`만 읽습니다. 다만 현재 참가자의 시즌 랭크가 없거나
설정한 재사용 시간이 지났으면 듀오 검사와 함께 League-v4를 한 명당 한 건만 조회해 저장합니다. 각 참가자의 최신 솔로랭크
경기 상세도 기존 40건 상세 요청 예산 안에서 우선 저장해 전판 챔피언·포지션·승패·K/D/A·KDA를 표시합니다.
로컬에 없는 처음 만나는 플레이어는 `로컬 데이터 없음`으로 표시되며, 게임 종료 후 본인 전적과 방금 만난
플레이어의 관계 기록이 자동으로 저장됩니다. 처음 최대 1,000경기를 받는 작업은 개발용 Riot API 키의
속도 제한 때문에 몇 분 이상 걸릴 수 있지만, 이후에는 신규 경기 상세만 받습니다.

Riot Live Client API에는 공식 파티 ID가 없으므로 듀오는 확정값이 아닙니다. 듀오 검사만 게임 시작 후
예외적으로 Riot API를 사용합니다. 현재 10명 각각의 최근 솔로랭크 100경기 ID는 1명당 한 요청으로 받고,
같은 팀 두 사람에게 공통 경기 ID가 있을 때만 상세를 확인합니다. 계정 확인 10건, ID 목록 10건, 시즌 랭크
10건, 경기 상세 40건으로 한 게임 최대 약 70건을 넘지 않습니다. 한 쌍당 공통 경기 상세도 최대 5건만
확인합니다.

- `DUO 매우 유력`: 서로의 직전 2경기가 모두 같은 팀
- `DUO 유력`: 직전판도 같은 팀이라 현재 게임까지 2연속이거나, 최근 기록 안에서 2경기 연속 같은 팀
- `DUO 가능`: 연속은 아니지만 최근 100경기 안에서 같은 팀으로 2회 이상 확인

직전 경기가 아닌 한 번의 우연한 동팀 기록만 있으면 배지를 표시하지 않습니다.

## OP.GG 주의사항

OP.GG는 공개 집계 API를 제공하지 않으므로 공개 웹페이지를 낮은 빈도로 읽는 방식입니다. 페이지 형식이
바뀌면 파서가 임의의 수치를 표시하지 않고 갱신 실패로 처리합니다. 마지막 정상 캐시는 유지됩니다.

## League Client 적용 주의사항

빌드 적용은 로컬 League Client API(LCU)를 사용합니다. Riot은 이 인터페이스를 제3자용으로 공식
지원하거나 안정성을 보장하지 않으므로 클라이언트 패치 후 일시적으로 동작하지 않을 수 있습니다.
자동 수락·럭스 자동 밴은 기본 OFF이며 사용자가 켠 경우에만 동작합니다. 그 외 픽·밴·빌드는 각 버튼을
직접 누른 경우에만 요청합니다. 실행 전 최신 챔피언 선택 세션을 다시 검사하고, 실패하면 클라이언트에서
직접 처리하도록 즉시 알립니다. 룬은
`LOL Advisor · 챔피언 · 포지션` 페이지를 생성·갱신하고, 아이템은 같은 이름의 추천 세트만 갱신합니다.
LCU를 사용하는 제품을 배포할 경우 Riot 개발자 정책에 따라 제품 등록과 기능 공개가 필요합니다.
